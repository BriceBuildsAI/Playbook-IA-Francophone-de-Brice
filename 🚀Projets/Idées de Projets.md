# Portfolio de projets d'agents IA

Cette page regroupe plusieurs idées de projets d'agents IA orientés Business Analysis.

L'objectif est de construire progressivement un portefeuille de réalisations permettant de mettre en pratique les concepts liés à l'IA générative, aux agents IA, à Microsoft Copilot et à Copilot Studio.

---

# Projet 1 - BA Assistant

## Objectif

Transformer un besoin métier en artefacts exploitables par une équipe projet.

## Entrée

- Expression de besoin
- Compte-rendu d'atelier
- Demande métier

## Sorties attendues

- User Stories
- Critères d'acceptation
- Cas de test

## Valeur apportée

- Accélération du cadrage
- Homogénéisation des livrables
- Gain de temps pour les Business Analysts

# Projet 3 - Agent Support Fonctionnel

## Objectif

Aider à la qualification des incidents et des anomalies.

## Entrée

- Description d'une anomalie
- Signalement utilisateur
- Incident applicatif

## Sorties attendues

### Qualification

- Questions complémentaires à poser
- Informations manquantes

### Analyse

- Causes potentielles
- Pistes d'investigation

### Ticket prérempli

- Résumé
- Description
- Étapes de reproduction
- Informations techniques

## Intégrations possibles

- Jira
- Azure DevOps
- ServiceNow

## Valeur apportée

- Qualification plus rapide
- Tickets de meilleure qualité
- Réduction des allers-retours avec les utilisateurs

# Projet 4 - Agent Documentation

## Objectif

Faciliter la recherche et l'exploitation de la documentation projet.

## Base de connaissances

### Sources documentaires

- SharePoint
- Documentation projet
- Procédures métier
- Guides utilisateurs
- Documentation technique

## Fonctionnalités

- Question-réponse sur le projet
- Recherche documentaire
- Synthèse de documents
- Identification de documents pertinents

## Approche

RAG (Retrieval Augmented Generation)

```text
Question utilisateur
        ↓
Recherche documentaire
        ↓
Sélection des documents pertinents
        ↓
Génération de la réponse
```

## Valeur apportée

- Accès rapide à l'information
- Réduction du temps de recherche
- Capitalisation des connaissances projet

# Perspectives d'évolution

Ces projets constituent une base pour :

- Microsoft Copilot Studio
- Agent Builder
- Power Automate
- MCP (Model Context Protocol)
- Agents autonomes
- Architectures multi-agents

L'objectif est de construire progressivement un portefeuille démontrant l'application concrète de l'IA aux activités du Business Analyst.
