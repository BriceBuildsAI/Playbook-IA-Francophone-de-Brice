# Roadmap de montée en compétences IA

## Objectif

Cette roadmap décrit les compétences à acquérir progressivement pour évoluer vers un profil de Business Analyst spécialisé en IA, agents IA et solutions Microsoft Copilot.

L'objectif n'est pas de devenir développeur, mais de comprendre suffisamment les concepts, les outils et les architectures pour cadrer, concevoir et piloter des projets IA.

---

# Phase 1 - Fondations opérationnelles

## Objectif

Maîtriser les outils Microsoft permettant d'utiliser et de construire des solutions IA dans un contexte professionnel.

### Compétences

✅ Microsoft 365 Copilot

✅ Prompt Engineering

✅ Copilot Studio

✅ Power Automate

✅ Applied Skills Microsoft Copilot Studio

### Résultat attendu

Être capable de :

- utiliser efficacement l'IA au quotidien ;
- créer des agents avec Copilot Studio ;
- automatiser des processus simples ;
- préparer et réussir les certifications Applied Skills Microsoft ;
- accompagner les métiers dans l'adoption de l'IA.

---

# Phase 2 - Industrialisation et gouvernance

## Objectif

Comprendre comment les solutions IA sont alimentées, sécurisées et gouvernées.

### Compétences

✅ RAG (Retrieval Augmented Generation)

✅ Dataverse

✅ Gouvernance IA

✅ AI Act

✅ Sécurité

### Résultat attendu

Être capable de :

- comprendre les mécanismes de recherche documentaire ;
- exploiter les données d'entreprise ;
- dialoguer avec les équipes sécurité ;
- prendre en compte les exigences réglementaires ;
- cadrer des projets IA conformes et robustes.

---

# Phase 3 - Comprendre l'écosystème Agentic AI

## Objectif

Découvrir les concepts qui structurent les architectures modernes d'agents IA.

### Compétences

✅ Comprendre LangChain

✅ Comprendre LangGraph

✅ Comprendre MCP (Model Context Protocol)

### Résultat attendu

Être capable de :

- comprendre les architectures d'agents modernes ;
- dialoguer efficacement avec les équipes techniques ;
- comprendre les concepts d'orchestration ;
- identifier les solutions adaptées à un besoin métier ;
- suivre les évolutions du marché de l'IA agentique.

### Important

L'objectif n'est pas nécessairement de devenir développeur.

L'objectif est de :

- comprendre ;
- concevoir ;
- cadrer ;
- piloter ;
- challenger les solutions proposées.

---

# Vision cible

À terme, cette montée en compétences doit permettre d'intervenir sur des sujets tels que :

- AI Business Analyst
- AI Product Owner
- Copilot Studio Agent Builder
- AI Automation Consultant
- AI Governance Consultant
- AI Solution Architect (à plus long terme)

---

# Principes de progression

1. Utiliser l'IA
2. Construire des agents
3. Automatiser des processus
4. Comprendre les architectures
5. Concevoir des solutions
6. Piloter des projets IA
